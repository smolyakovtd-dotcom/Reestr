# Настройка хранения сканов в локальной сети

## 1) Укажите путь к сетевой папке

В файле `config.php` задайте `SCANS_STORAGE_PATH` как UNC-путь:

```php
const SCANS_STORAGE_PATH = '\\\\fileserver\\share\\reestr_scans';
```

Пример:

- `\\fileserver\share\reestr_scans`

## 2) Настройте права на сетевую папку

Папка должна быть доступна на запись для учетной записи, под которой запущен PHP/веб-сервер.

Нужно разрешить:

- создание файлов;
- удаление файлов;
- создание подпапок.

## 3) Проверьте роли и доступ

В системе действуют роли:

- `warehouse` - полный доступ к реестру;
- `viewer` - только просмотр;
- `scanner` - просмотр + загрузка/удаление сканов.

Важно:

- кнопки `Upload/Delete` для сканов доступны только роли `scanner`;
- остальные роли могут только просматривать список и скачивать файлы.

## 4) Быстрый тест после настройки

1. Войти под ролью `scanner`.
2. Загрузить файл в карточке документа.
3. Проверить скачивание файла.
4. Проверить удаление файла.
5. Войти под `viewer`/`warehouse` и убедиться, что `Upload/Delete` отсутствуют.
